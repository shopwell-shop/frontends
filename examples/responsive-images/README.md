# Blank playground

This example should help get you started developing [Shopwell Frontends](https://github.com/shopwell-shop/frontends).

## Customization

- edit [./src/App.vue](./src/App.vue) in order to change the current example
- edit [./src/main.js](./src/main.js) in order to adjust Shopwell Frontends plugin

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
